## Choose a deployment mode

Both deployment modes create the same logical architecture in namespace `client-side-defense`:
one origin pool and one `client-side-defense` HTTP load balancer for
`client-side-defense.f5-sales-demo.com`. The load balancer uses HTTPS automatic certificates,
redirects HTTP to HTTPS, advertises on the public default VIP, routes to the origin pool, and
inserts Client-Side Defense JavaScript on all pages.

- [API build](/csd/en/demo/phase-1-build/) — create and operate the F5 Distributed Cloud resources directly.
- [Terraform](/csd/en/terraform/) — deploy the AWS origin and F5 Distributed Cloud resources as one state-managed stack.

The AWS reference uses the Application Load Balancer hostname as a `public_name` origin. An
Azure origin uses its `public_ip` address instead.

Choose one ownership mode. Never run the API create/update/delete workflow against resources present in Terraform state.
